# WEB103 Prework - Creatorverse

Submitted by: **Your Name Here**

Creatorverse is a web application that allows users to share, view, edit, and delete their favorite content creators. Users can explore creators, visit their channels, and manage creator entries through a clean and responsive interface.

---

## 🚀 Features

The following **required features** are completed:

- [x] A logical React component structure
- [x] Displays at least five content creators
- [x] Each creator includes name, URL, and description
- [x] Users can view a single creator with unique routing
- [x] Users can add new creators
- [x] Users can edit existing creators
- [x] Users can delete creators
- [x] Async API calls using Supabase
- [x] Each creator has a unique URL

The following **stretch features** are implemented:

- [x] Styled using PicoCSS
- [x] Creator cards instead of a list
- [x] Creator images displayed (optional field)

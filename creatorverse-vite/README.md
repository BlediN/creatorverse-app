# WEB103 Prework - *👉🏿 Creatorverse-App*

Submitted by: **👉🏿 Bledar Ndoni**

About this web app: **👉🏿 Creatorverse-App is a React-based web application that allows users to discover, view, add, edit, and delete popular tech content creators. The app features a responsive card-based layout, integrates with Supabase for data storage, and provides a clean, modern user interface styled with PicoCSS.**

Time spent: **👉🏿 10** hours

## Notes

One of the main challenges was creating a responsive and visually consistent card layout while handling images of different sizes and varying text lengths. This was addressed by using fixed image containers, flexbox layouts, and CSS line clamping. Additional effort was spent refining the user experience through animated floating labels, responsive spacing, and improved form validation.
